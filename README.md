# ROBY'S · 3D Coffee House Experience

**Отдельный проект:** интерактивная, приближённая 3D-реконструкция кофейни Roby's Coffee House в Газипаше, созданная по четырём предоставленным фотографиям посетителей.

![Status](https://img.shields.io/badge/status-experimental-D3A77B) ![Three.js](https://img.shields.io/badge/Three.js-3D-202A24)

> **Важно:** это фото-информированный **художественный макет**, а не фотограмметрия и не точный обмер помещения. Отношения размеров и невидимые элементы предположительны. Утверждать о точности по четырём кадрам нельзя.

## Что уже есть

- Полноценная сцена на Three.js (не плоское изображение): фасад, терраса с посадкой, интерьер, центральный серый объём, витрина с десертами, стойка, металлическая антресоль, условная лестница, верхняя посадка.
- Четыре камеры-ракурса: **Фасад**, **Главный зал**, **Антресоль**, **Второй этаж**.
- Плавная орбитальная камера, приближение, режим прогулки с WASD/стрелками; сенсорное вращение и мобильный D-pad.
- Переключение **День / Вечер**.
- Простые проверки столкновений с основными столами и витриной, ограничения карты для первого/второго уровня.
- Адаптивный интерфейс, диалог с ограничениями, кнопка полноэкранного режима.
- Базовые Node-тесты для навигации, CI для GitHub Pages.

## Локальный запуск

Для локального сервера требуется Python 3; для тестов — Node.js 20+. Установка npm-пакетов **не нужна**. Рендер Three.js подгружается с jsDelivr CDN, поэтому для первого запуска браузеру нужен интернет.

```bash
python3 -m http.server 5173
```

Открой ссылку из терминала (обычно `http://localhost:5173`).

```bash
npm test
```

## Публикация

1. Создай **новый**, пустой репозиторий GitHub `robys-3d-experience` (основной `robys-coffee-house-demo` не изменяем).
2. Загрузи содержимое этого проекта, включая `.github/workflows/pages.yml`.
3. В GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Workflow `Deploy Roby's 3D to GitHub Pages` запускается при пуше в `main`; сборка будет опубликована по адресу `https://safal207.github.io/robys-3d-experience/` после успешного выполнения.

Для первого пуша:

```bash
git init -b main
git add .
git commit -m "feat: initial Roby's interactive 3D concept"
git remote add origin https://github.com/safal207/robys-3d-experience.git
git push -u origin main
```

## Исходные визуальные данные и авторские права

В работе использовались **четыре пользовательских скриншота** фотографий из Google-отзывов: 1) фасад и терраса, 2) главный зал и десертная витрина, 3) пространство под антресолью, 4) верхняя зона посадки. В репозиторий сами скриншоты **намеренно не добавлены**: у авторов фото могут быть права на их распространение. Текстуры и объекты генерируются программно; внешних изображений нет. Брендинг используется как обозначение объекта прототипа, без заявления об официальном представительстве.

## Ограничения MVP

- Нет точного масштабирования, реконструкции из глубины или сравнения с эталонным 3D-сканом.
- Условная лестница не предоставляет плавного непрерывного перехода между уровнями: уровни выбираются через навигацию.
- Текстуры упрощённые; десерты и растения условные; расположение отдельных стен и столов реконструировано предположительно.
- Встроенной синхронизации веб-камеры, экспорта `.blend`, заказа из меню или интеграции с существующим сайтом пока нет.
- Тестирование FPS требуется отдельно на целевых мобильных устройствах и браузерах.

## QA-план для следующей версии

1. Снять замеры ширины витрин, высоты этажа, ширины антресоли и расстояния до лестницы.
2. Получить дополнительные изображения с противоположных ракурсов, привязать контрольные точки, проверить вид третьей камерой.
3. Добавить автоматизированные E2E-тесты Playwright (включая мобильные viewport), бюджет производительности и скриншотные диффы.
4. Добавить интерактивные модели продукции из актуального каталога Roby's и CTA «Открыть меню».
5. Экспорт сцен в `.glb`, затем в `.blend` через Blender/GLTF-import для дальнейшей редакции.
